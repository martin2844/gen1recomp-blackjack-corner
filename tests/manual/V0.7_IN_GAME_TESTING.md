# v0.7.0 in-game testing plan

This is the required release gate for the Underground Arena. Run every critical
case on both Pokemon Red and Pokemon Blue. Automated tests own formulas,
migrations, idempotency, and malformed data. This plan owns navigation,
readability, animation, input, save/reload behavior, and the feel of watching a
live fight at native Game Boy resolution.

## Automated baseline

From the Gen1Recomp host root, synchronize the development copy and run every
mod test:

```sh
rsync -a --delete --exclude=.git \
  /absolute/path/to/gen1recomp-blackjack-corner/ \
  mods/blackjack_corner/

for test in mods/blackjack_corner/tests/*_test.lua; do
  luajit "$test" || exit 1
done
```

Also run manifest validation, lint, and a release-pack validation before
signoff. A passing headless suite does not replace the two native runs below.
