# v0.6.0 in-game testing plan

This is the required human release gate for Rocket Credit. Run every critical
case on both Pokemon Red and Pokemon Blue. Automated tests prove state and
economy invariants; this plan verifies navigation, dialogue, input, battle,
save/reload behavior, and Game Boy-scale presentation in the real engine.

## Launch commands

From the Gen1Recomp host root, first synchronize the standalone repository:

```sh
rsync -a --delete --exclude=.git \
  /absolute/path/to/gen1recomp-blackjack-corner/ \
  mods/blackjack_corner/
```

Then run a driver, substituting Red or Blue and unique directories:

```sh
POKEPORT_DRIVER=/absolute/path/to/gen1recomp-blackjack-corner/tests/manual/drivers/rocket_credit_bailout.lua \
POKEPORT_IDENTITY=blackjack-corner-v06-red-bailout \
SHOT_DIR=/tmp/blackjack-corner-v06/red/bailout \
POKEPORT_IMPORT_ROM=./red.gb POKEPORT_FORCE_IMPORT=1 \
love .
```

For Blue, use `blue.gb`, set `POKEPORT_VERSION=blue`, and use a new identity.
Wait for `MANUAL CONTROL READY`; the driver then stops pressing buttons.
