Findings fixed during supervised review:

- Replaced fixed Lounge object IDs with collision-safe IDs derived from the
  live map, protecting compatibility with other content patches.
- Made deterministic fighter selection bounded even when an injected RNG
  repeatedly returns the same value.
- Expanded the initial 25-case driver into a 35-case arena gate after finding
  that the first draft did not exercise every documented failure path.
- Corrected an impossible acceptance case: Arena play starts at KINGPIN, so an
  arena result cannot itself award KINGPIN. The gate now tests the real handoff
  from an existing game into the rank presentation and lift unlock.
- Replaced an unreachable hand-authored sudden-death checkpoint with the
  longest real fight produced by 500 cards, so the gate reports only behavior
  that actually ran.
- Shortened only the fighter prefix when a long attack caption would overflow,
  preserving full move names and damage text inside the 160×144 frame.
