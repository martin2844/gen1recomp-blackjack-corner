  reveals a complete native staircase rather than teleporting the player.
- [x] B1 and B2 use imported `LOBBY` and `GYM` blocks, physical reciprocal
  warps, permanent Rocket staff, and an untouched player party.
- [x] Six B1 cabinet seats open the original Gen1Recomp slot-machine screen.
- [x] Hotkey `2` recolors both underground rooms across native palette modes on
  Red and Blue.
- [x] Real disk restores in the Lounge, B1, and B2 retain valid position,
  collision, party state, staircase state, and every return path.
- [x] The complete 37-case Arena audit passes on Red and Blue, including both
  favorite and underdog wins in the seeded odds sample.

## UI and compatibility

- [x] Normal and stress High Roller panels keep rank, REP, records, lifetime
  wager, favorite game, and banked rewards inside fixed columns.
- [x] Arena arrows communicate up/down fighter selection and left/right wager
  changes at native resolution.
- [x] Hearts, diamonds, clubs, and spades remain distinct on Ace and ten-card
  layouts; the Ace of Spades silhouette remains unchanged.
- [x] Schema-three v0.5.0 saves already located in either underground map reveal
  the replacement staircase before returning to the Lounge.
- [x] Legacy development saves with a held party recover it once; ordinary
  Arena traversal never removes or mutates the player's party.
